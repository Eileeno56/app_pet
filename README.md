Compara el hash antes de instalar. Esta beta conserva la firma de las versiones anteriores; la firma del APK beta.4 está verificada. Utiliza firma de depuración y no puede actualizar instalaciones con otra firma. Conserva tus fotografías locales antes de desinstalar una versión anterior. Sigue las indicaciones de Android sin desactivar sus protecciones.

La distribución actual se centraliza en **Eileeno56/pet**, junto con el código, tags, releases y evidencias. Este repositorio conserva los reportes originales y versiones anteriores.

La beta.4 exige confirmar el correo con el enlace de Firebase antes de acceder. Conserva Spark; no necesita Blaze ni contraseña de Gmail. Incluye acceso con tiempos de espera, validaciones mejoradas, información centrada y fondo de corazones y patitas, horarios por días, comidas manuales, historial con filtros y porcentajes, plan de alimento, ficha médica y cuidado familiar mediante invitaciones dentro de la app. Las reglas nuevas de Firebase ya están desplegadas.

Actualización beta.4: registro desde 8 caracteres con mayúscula, minúscula, número y símbolo, indicador rojo/amarillo/verde y bloqueo de nuevos nombres duplicados por espacio.
